WHAT'S IN HERE
--------------
Two complete scenes from the full 40-image pack, with all their lighting
states:

  street: day / evening / night / rain
  study:  day / evening / candlelit / fire

Same scene, same camera, same objects in every state. Only the light and
weather change, so you can swap them mid-scene and nothing pops in or out.

FILE NAMING
-----------
vm_bg_<scene>_<state>.png

REN'PY QUICKSTART
-----------------
Drop the PNGs into your project's game/images/ folder. Ren'Py defines an
image for each file automatically, named after the filename:

    scene vm_bg_street_day
    "A quiet morning on Harrow Lane."

    scene vm_bg_street_rain with dissolve
    "By nightfall, the weather had opinions."

If you prefer the attribute style, also copy the included vm_bg_images.rpy
into your game/ folder, and this works too:

    scene vm_bg street rain with dissolve

They are plain 1920x1080 PNGs, so any other engine takes them too.
